La télé n’est pas joignable depuis le cloud

Vercel est sur Internet. Ta télé est derrière ton Wi‑Fi (NAT). Il faut un pont chez toi : un petit serveur sur le même réseau que la télé, exposé en HTTPS, que le site Vercel appelle.

Sur l’ordinateur à la maison (même Wi‑Fi que la télé) :

git clone https://github.com/samkompany/remote-tv.git cd remote-tv && npm install export VERCEL_APP_URL=https://TON-APP.vercel.app npm run share

Le terminal affiche un lien à envoyer. Les autres ouvrent ce lien : l’UI Vercel + le pont vers ta télé.
